# High-Fidelity UI Design

## Task
Convert a wireframe into a **high-fidelity UI design** by adding:
- Color palette
- Typography
- Buttons
- Icons
- Images
- Responsive layout
- UI/UX principles

## Project
This project is a responsive UI showcase built with **HTML, CSS and JavaScript**.

### Features
- Modern navigation bar
- Hero section with clear call-to-action buttons
- Dashboard preview card
- Design-system feature cards
- Button and color-palette components
- Image-based showcase section
- Responsive mobile layout
- Interactive toast messages

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your browser.

You can also open the folder in VS Code and use the **Live Server** extension.

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts (Inter)
- Unsplash image

## UI/UX Principles Used
- Visual hierarchy
- Consistent spacing
- Color contrast
- Clear call-to-action buttons
- Responsive design
- Familiar icons and controls
- Accessible readable typography
