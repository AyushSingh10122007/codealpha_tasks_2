#  High-Fidelity UI Design

# Task 2: High-Fidelity UI Design

This project converts a basic wireframe into a **high-fidelity UI design** by adding modern colors, typography, buttons, icons, images, and responsive layouts.

The design follows important **UI/UX principles** to provide a clean, simple, and user-friendly experience.

---

# Project Overview

The website is a modern UI showcase that demonstrates how a wireframe can be converted into a polished high-fidelity interface.

# Main sections:
-  Navigation Bar
-  Hero Section
-  Dashboard Preview
- Design System
- UI Components
-  Color Palette
-  Image Showcase
-  Responsive Design
-  Interactive Buttons

---

## 🛠️ Technologies Used

- *HTML5* – Website structure
- *CSS3* – Styling, colors, layout and responsive design
-*JavaScript* – Button interactions
- *Google Fonts* – Inter typography
- *Unsplash* – UI design image

---

###  UI/UX Features

# 1. Color Palette
A modern color system is used to create visual consistency.

- Primary: Purple
- Success: Green
- Warning: Orange
- Dark: Black/Dark Gray
- Background: Light Gray/White

# 2. Typography
The **Inter** font is used for clean and readable text.

# 3. Buttons
The project contains:
- Primary button
- Secondary button
- Dark button
- Hover effects

# 4. Icons
Simple icons are used to make navigation and feature sections easier to understand.

# 5. Images
Images are included to improve the visual appearance and demonstrate visual storytelling.

# 6. Responsive Design
The website works on:
-  Desktop
-  Mobile
-  Tablet
